# Бот дешёвых авиабилетов из Астаны

Каждые 3 часа бот проверяет цены через Travelpayouts (Aviasales) и пишет в Telegram:
- 🔥 **Ниже рынка**: билет на 25%+ дешевле обычной цены по направлению;
- ✅ **В бюджете**: туда-обратно до 200 000 ₸ на человека;
- 📉 **Подешевело**: вариант, который уже присылал, стал дешевле;
- 📊 **Сводка раз в день** (около 9:00 по Астане): лучшая цена по каждому направлению.

Цены в Aviasales — это то, что находили пользователи за последние дни. Перед покупкой проверяйте цену по ссылке.

## Установка (10 минут, один раз)

1. Зарегистрируйтесь на https://github.com и нажмите **New repository**.
   Название, например, `travel-bot`, тип **Private**, затем **Create repository**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите все файлы из архива,
   включая папку `.github`. Если папку не видно, включите показ скрытых файлов. Нажмите **Commit changes**.
3. Откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте два секрета:
   - `TP_TOKEN`: токен Travelpayouts;
   - `TG_TOKEN`: токен Telegram-бота от @BotFather.
4. Напишите своему боту в Telegram любое сообщение, например «привет».
5. Откройте вкладку **Actions → «Проверка цен» → Run workflow**.
   Через минуту бот пришлёт приветствие и первую сводку.

Дальше бот работает сам.

## Как поменять настройки

Откройте `config.json` на GitHub и нажмите на карандаш:
- `departure_from` / `departure_to`: окно дат вылета;
- `nights_min` / `nights_max`: сколько ночей;
- `budget_per_person_kzt`: потолок цены билета туда-обратно на человека;
- `deal_discount_percent`: насколько ниже рынка считать находкой;
- `destinations`: направления (коды аэропортов IATA).
